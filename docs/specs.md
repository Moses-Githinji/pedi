## 🧠 3. The "Hero" Algorithm (Logic Flow)

The TikTok-style experience relies on a **Interest Scoring Engine**. Since we are using Firestore, we use a hybrid approach:

1. **Onboarding Filter:** Initial fetch queries `gems` where `tags` array contains `user.preferences`.
2. **Engagement Scoring:**
* **Watch Time > 80%:** +5 points to that tag.
* **Vouch (Like):** +10 points.
* **Skip < 2s:** -5 points.


3. **Real-time Recalibration:** A **Firebase Cloud Function** runs every 10 interactions to update the `user.preferenceWeights` object, which the frontend uses to re-sort the local stream.

## 🛡️ 4. The "Vibe-Meter" & Verification System

To maintain the "Pedi" reputation, we implement a **Double-Factor Verification**:

* **Proof of Presence (PoP):** The "Vouch" button is only active if `distance(User.GPS, Gem.GPS) < 500m`.
* **The "Cap" Trigger:** If a post receives a `capCount` that is >30% of its `vouchCount`, a Cloud Function flags it for manual review or hides it from the "Encyclopedia" search.
